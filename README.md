# Golang Backend - Neobank System
Proyek latihan backend engineering, arsitektur API, validasi transaksi, JWT authentication, concurrency (goroutines & worker pools), serta optimasi performa menggunakan Go.

## Daftar Latihan:
1. REST API Sederhana (main.go)
2. Validasi Transaksi & Error Handling (transaction.go)
3. Simulasi Koneksi Database (database.go)
4. JWT Authentication Middleware (auth.go)
5. Concurrency Worker Pools (advanced_worker.go)
6. Performance Optimization dengan sync.Pool (optimize_pool.go)
